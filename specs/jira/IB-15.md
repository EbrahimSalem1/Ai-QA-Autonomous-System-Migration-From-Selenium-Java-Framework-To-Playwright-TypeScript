## Story
**As a** shopper **I want to** search the catalogue by keyword **so that** I can quickly find products.

## Acceptance criteria
- **AC1 — Existing product:** search **iPhone** → results contain **iPhone**.
- **AC2 — Partial keyword:** search **mac** → more than one result, every name contains "mac" (case-insensitive).
- **AC3 — No results:** unknown keyword → **There is no product that matches the search criteria.**

**Out of scope:** category filters, sorting, pagination, description search.
